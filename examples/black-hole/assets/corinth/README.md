# Corinth Cargo Transporter — shot mesh

By **Yvo Pors**, [original model](https://sketchfab.com/3d-models/corinth-cargo-transporter-7614d85856f6477ba2a603970dcbb0dd),
licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
See the retained `license.txt`.

This derivative has 24,158 triangles. Each source mesh was simplified with
Blender's collapse decimator at ratio 0.2. Textures were resized to 512×512;
opaque textures use JPEG quality 82, while alpha textures retain PNG. glTF
transforms, UVs, normals and material assignments are preserved. Roughness is
scaled to 0.55 and metallic weight to 0.65 for the disk-lit flyby; base-color
textures receive a 1.7× linear exposure lift. `bounds.json` records the transformed
accessor bounds used to centre and scale the asset. The entire asset is about
2.3 MB; the full-resolution source is deliberately not stored in this repository.
