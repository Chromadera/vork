buffers use that prefix (e.g. box, box_position, box_normal, box_TEXCOORD_0, box_indices).

round shapes use Y as axis. Cylinder has both caps; cone has a bottom cap; size = full extent; capsule height includes
caps; torus radius is to the tube centre. Radii and bevels clamp to fit without overlap, scaling unequal corners together; extrusion rims fit depth/2 and profile clearance. Negative or non-finite values are errors. Rounded box segments subdivide the bevel
(rounded up to an even count), preserving exact planar faces at every count. Box faces each span 0..1 UV; round shapes: u from +X toward
-Z around Y, v top to bottom.

std.procedurals: noise, noise_color, voronoi, white_noise, gabor.
Slang signatures below: p is float3; scalar inputs float except dimensions:int and normalize:bool.
noise(p, scale=5, detail=2, roughness=.5, lacunarity=2, distortion=0, normalize=true,
  type=NoiseType.FBM, dimensions=3, w=0, offset=0, gain=1) → float.
noise_color: same inputs → float3, independently seeded channels.
NoiseType: FBM|Multifractal|Hybrid_Multifractal|Ridged_Multifractal|Hetero_Terrain (case-sensitive).
FBM with normalize=true is centred on .5, range [0,1]; other modes/un-normalized values may exceed it.
Detail adds octaves beyond the base (0..15, fractional blends); dimensions 1..4; 1D uses w, 4D adds w.
voronoi(p, scale=5, randomness=1, feature=VoronoiFeature.F1, metric=DistanceMetric.Euclidean,
  smoothness=1, exponent=.5, dimensions=3, w=0, detail=0, roughness=.5, lacunarity=2,
  normalize=false) → {distance:float, color:float3, position:float3, w:float, radius:float}.
VoronoiFeature: F1|F2|Smooth_F1|Distance_To_Edge|N_Sphere_Radius.
DistanceMetric: Euclidean|Manhattan|Chebychev|Minkowski (exponent controls Minkowski).
Distances/radius use cell space; position/w locate features in input space; color identifies cells.
Smooth_F1 is a smooth minimum and can undershoot zero (including color). normalize divides
distance by weighted cell diagonal; not a clamp.
white_noise(p, dimensions=3, w=0) → {value:float, color:float3} in [0,1]; hashes coordinates, no cells.
gabor(p, scale=5, frequency=2, anisotropy=1, dimensions=2, orientation=.7853981634,
  direction=float3(1.41421356237,1.41421356237,0)) → {value:float, phase:float, intensity:float}, [0,1].
Gabor uses 2D XY/orientation radians, otherwise 3D/direction; anisotropy 0=random, 1=aligned.

std.particles: Yu–Turk anisotropic particle-surface mathematics (ACM TOG 2013).
  particle_moment(inout ParticleMoments, relative:float3, neighbourhood_radius:float):
    accumulate weighted relative moments within compact support; initialize moments to zero.
  particle_metric(moments, radius, neighbourhood_radius, minimum_neighbours:uint,
    maximum_ratio, out support:float) → float3x3 world-to-kernel metric.
    Positive radii and maximum_ratio >= 1 required; sparse neighbourhoods use a sphere.
    Radius is the isotropic compact support; covariance normalization is scale invariant.
  particle_kernel(relative:float3, metric:float3x3) → normalized 3D cubic density.
  particle_cubic(q:float) → radial cubic shape, q >= 0, zero for q >= 1.
  Fit from a retained particle generation, then evaluate from a separate dispatch.
  Neighbour search must cover returned support plus any authored centre relocation.
  Density normalization, surface isovalue and particle relocation belong to the caller.
